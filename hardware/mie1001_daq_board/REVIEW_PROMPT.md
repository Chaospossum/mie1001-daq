## The design
Folder: ~/projects/mie1001_daq_board (KiCad 10). Read README.md first.
An Arduino UNO R3 shield for a portable quadrupole mass spectrometer:
- Detector current (pA to uA) -> BNC J1 -> R4 1k (+ BAV199 D1 clamp to VREF) -> LMP7721
  transimpedance amp U4 (feedback 2M2 or 100M via jumper JP1, C1 10pF) -> R3/C2 1k/1uF
  -> ADS1115 U2 AIN0, differential against AIN1 = VREF (2.5 V mid-supply, buffered by U3B).
- MCP4725 DAC U1 -> MCP6002 buffer U3A -> R12 100R -> J2 (QPS mass command, 0-5 V),
  read back on ADS1115 AIN2 via R13.
- I2C on the UNO's dedicated SDA/SCL pins; ADS1115 ALERT/RDY -> D2; trigger J4 -> D8.
- All power from the UNO 5 V (USB). 2-layer board, UNO R3 outline.
Both the schematic and the PCB are GENERATED by generate_schematic.py and
generate_pcb.py; ./build.sh rebuilds everything and runs ERC, DRC and check_guard.py.
Official datasheets are in datasheets/. Rendered images: fab/board_top.png,
fab/assembly_top.pdf, mie1001_daq_board.pdf (schematic).

## Rules for this review
- For every claim, cite the evidence: datasheet file + page/table, or file + line, or the
  command you ran and its output. If you cannot verify something, say "UNVERIFIED" instead
  of guessing. Do not answer from memory when a datasheet is in datasheets/.
- Run ./build.sh yourself and read erc.rpt and drc.rpt. Expected: ERC 0; DRC 0 errors,
  0 unconnected, 0 schematic parity issues, and exactly 4 lib_footprint_mismatch warnings
  (J1, J2, J4, A1 are deliberately modified copies). Anything else is a finding.
- Separate real defects from preferences. Rank findings by severity.

## Check each of these
1. PINOUTS. For U1 MCP4725A0T-E/CH (SOT-23-6), U2 ADS1115IDGSR (MSOP-10), U3 MCP6002-I/SN
   (SOIC-8), U4 LMP7721MA/NOPB (SOIC-8, non-standard pinout) and D1 BAV199LT1G (SOT-23):
   export the netlist (kicad-cli sch export netlist) and compare every pin's net with the
   datasheet pin table. Also check each symbol's pin numbers match its footprint's pad
   numbers, and that the UNO header pads (Module:Arduino_UNO_R3) match the UNO pinout.
2. ELECTRICAL. Supply and abs-max at 4.75-5.25 V for every part; ADS1115 inputs stay in
   GND..VDD; I2C addresses (expect 0x48 and 0x60); TIA stability with C1 = 10 pF for both
   feedback resistors and ~100 pF of detector cable; LMP7721 input common-mode range at
   VREF = 2.5 V; MCP6002 driving a cable through R12; the anti-alias filter vs the 860 SPS
   max data rate; what the QPS output does at power-up.
3. PICOAMP INPUT. The nets /TIA_IN and /DET_IN must be surrounded only by the VREF guard
   (pours on both layers) and feedback parts. Run check_guard.py and inspect the layout
   around U4, R4, C1, JP1, D1 and J1 pin 1. Report any other net closer than 1 mm, any
   leakage path from +5V or GND into those nets, and whether the guard really encloses them
   on both layers (compare with LMP7721 datasheet section 10, Layout).
4. POWER AND GROUND. Decoupling cap at each IC's supply pin, ground via at every SMD
   ground pad, ground pours not split into islands, no ground copper inside the guard.
5. MECHANICAL. Board outline and header positions vs the UNO R3 drawing
   (datasheets/Arduino_UNO_R3_A000066.pdf); the BNC J1 front flush with the right edge; no
   through-hole leads or bottom copper above the UNO's USB-B jack, DC jack or ICSP header;
   mounting holes; terminal blocks J2/J4 fitting between the DC and USB jacks.
6. MANUFACTURING. Track/clearance/drill vs JLCPCB standard 2-layer capabilities;
   fab/jlcpcb_bom.csv has an LCSC part for every SMD part and each LCSC number is the right
   part and package; fab/jlcpcb_cpl.csv rotations: for U1-U4 and D1, state what rotation
   JLCPCB will need so pin 1 lands on the pad-1 mark (KiCad and JLC zero angles differ).
7. SILKSCREEN AND USABILITY. Connector labels correct (J2: 1 = OUT, 2 = GND; J4: 1 = IN,
   2 = GND; J3: 1 = VREF, 2 = AIN3, 3 = GND; JP1: 1-2 = 2M2, 2-3 = 100M), pin-1 marks visible.
