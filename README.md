# MIE1001 Team 5 — data acquisition for the portable quadrupole mass spectrometer

Foundation of Imaging Engineering (MIE1001), Maastricht University, 2026.
Team 5 owns the data chain: detector signal → preamp → ADC → Arduino UNO → laptop, plus the DAC that
sends the mass command to the Extrel 150-QC quadrupole controller.

```
Faraday cup ─► preamp (LMP7721, 100 MΩ) ─► ADS1115 16-bit ADC ─I²C─► Arduino UNO ─USB─► laptop
                                               MCP4725 12-bit DAC ◄─I²C─┘ ─► mass command (0-5 V now; Extrel wants 0-10 V)
```

## Contents

| Folder | What |
|---|---|
| `firmware/` | Arduino sketches (open in the Arduino IDE; board: Arduino Uno) |
| `hardware/mie1001_daq_simple/` | **Simple shield, rev D**: plug-in ADS1115 + MCP4725 breakouts, screw terminals, and the Faraday-cup preamp. See its README |
| `hardware/mie1001_daq_board/` | **Full shield, rev E**: everything soldered (ADS1115, MCP4725, preamp), BNC input, CEM/Faraday ranges |

### Firmware

| Sketch | Tests | Serial |
|---|---|---|
| `ADS1115_selftest` | ADS1115 alone: reads the UNO's 3.3 V, GND and 5 V pins | 9600 |
| `MCP4725_standalone_test` | MCP4725 alone, read back on the UNO's A0; scans the I²C bus if not found | 9600 |
| `MCP4725_sine_scope` | MCP4725 sine wave, sent vs. read on the Serial Plotter | 115200 |
| `DAQ_loopback_test` | DAC → ADC loopback on the simple shield (wire QPS OUT to SIGNAL IN) | 115200 |
| `DAQ_mini_chain` | Breadboard chain: DAC → UNO A0 → PWM D9 → RC filter → ADS1115 | 115200 |
| `PwmGenerator` | Two-channel PWM generator on pins 9/10 (bench tool, not DAQ) | 115200 |

Libraries: Adafruit ADS1X15, Adafruit MCP4725. I²C addresses: ADS1115 0x48, MCP4725 0x60.

### Hardware

Both boards are **generated by Python** (`generate_schematic.py`, `generate_pcb.py`); `./build.sh` rebuilds the
KiCad files, runs ERC, DRC (with schematic parity) and the preamp guard check, and writes the JLCPCB files in
`fab/`. Edits made in the KiCad GUI are overwritten by the next build. Needs KiCad 10 (flatpak `org.kicad.KiCad`).
The simple board's PCB script reuses the router in `../mie1001_daq_board/`, so keep both folders side by side.
